# AI Companion — Frontend

React + TypeScript chat UI. Walking-skeleton increment: one chat screen, no
routing, no persisted history — see the root `SPEC.md` for the full v1 design.

## Setup

```bash
npm install
cp .env.example .env   # optional, default already points at localhost:8000
```

## Run

```bash
npm run dev
```

Open http://localhost:5173. The backend (see `../backend/README.md`) must be
running on http://localhost:8000.
